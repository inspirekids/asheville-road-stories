# Asheville Road Stories

A GPS audio driving tour for Dolores's birthday weekend: McDonald, TN to Asheville, NC and back, by US-64, US-74 and I-40.

Open **https://inspirekids.github.io/asheville-road-stories/** in Safari on an iPhone, tap **Start tour** and allow location. Each of the 18 recorded stories plays when you reach its spot.

- `index.html`: the tour page. It saves every recording when it opens, so it keeps working in the gorges without cell signal.
- `audio/`: the narration, recorded with the open-source Kokoro text-to-speech model (voice `af_heart`).
